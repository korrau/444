## GitHub Pages
1. Создай новый публичный репозиторий.
2. Загрузи `index.html` и папку `assets` целиком.
3. GitHub → Settings → Pages.
4. Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
5. Полученную ссылку можно записать в NFC-чип.

Не загружай только HTML: папка `assets` обязательна для фотографий и подписи.
